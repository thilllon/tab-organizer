# プライバシーポリシー - Tabinet

最終更新日: 2026年10月25日

## 概要

Tabinet は、ブラウザのタブを並べ替えて整理し、ウィンドウとタブのまとまりをセッションとして保存、復元、検索、インポート、エクスポートできる Chrome 拡張機能です。求めに応じて、YouTube タブの動画を一時停止することもできます。私たちはプライバシーを大切に考えています。この拡張機能が行うことはすべて、ブラウザの中、つまりお使いの端末の中で完結します。

## データの収集

Tabinet は個人データを**収集も送信もしません**。ネットワーク通信を行わず、閲覧したページの内容を読み取らず、アクセス解析、トラッキング、テレメトリーも使いません。すべての処理はブラウザ内でローカルに行われます。ウェブページの中で実行するのは YouTube 動画の一時停止だけで、それも許可された後に限ります（下の「YouTube 動画の一時停止」を参照）。

### 何を、どこに保存するか

セッションを保存したとき、および自動スナップショットが有効な間（下記参照）、拡張機能は開いているウィンドウについて次の情報を、この端末の Chrome のローカル拡張機能ストレージ（`chrome.storage.local`）にのみ保存します。

- 各タブ: URL、ページのタイトル、固定タブかどうか、アクティブなタブだったかどうか
- 各タブグループ: 名前、色、折りたたまれていたかどうか
- 各ウィンドウ: 状態（通常、最小化、最大化、全画面）、大きさと位置、フォーカスのあるウィンドウだったかどうか
- 各セッション: 付けた名前（または自動で付いた既定の名前）、保存日時と最終変更日時、同じスナップショットを二重に保存しないために使うタブ配置の短いフィンガープリント
- セッションの設定: 自動スナップショットのオン/オフ、間隔、保持する件数、大きなセッションの復元方法

シークレット ウィンドウ、空のウィンドウ、拡張機能自身のページは記録しません。Tabinet のページに表示されるサイトのアイコンは Chrome 自身のファビコン キャッシュから取得しており、拡張機能が保存することはありません。

これらのデータが端末の外に出ることはありません。Google アカウントで同期されることも、サーバーにアップロードされることもなく、ウェブページからアクセスすることもできません。セッションのデータが拡張機能の外に出るのは、ユーザーがエクスポートを選んだときだけです。エクスポートは、ユーザーが明示的に操作したときに限り、ファイルを作成するかテキストをクリップボードにコピーします。

並べ替えの設定（グループ化の方法と重複タブの扱い）と、設定で選んだ拡張機能の言語（選んだ場合）は、拡張機能のインストール時または更新時に記録したバージョン番号とともに Chrome の同期ストレージに保存されます。Chrome の同期を有効にしている場合、これらの設定、そしてそれだけが、同じ Chrome アカウントでログインしている端末間で同期されることがあります。セッションのデータとセッションの設定が同期ストレージに保存されることはありません。

### 自動スナップショット

自動スナップショットは**初期状態でオン**です。5分ごと（または1分から24時間の範囲で選んだ間隔ごと）、およびアイコンをクリックして並べ替えるたびに、拡張機能は上記のとおり開いているウィンドウの配置を記録します。ただし、前回のスナップショットから変化があった場合に限ります。スナップショットは保存したセッションと同じローカル ストレージに保存され、同じルールに従います。

スナップショットをオフにするには、Tabinet を開き（アイコンを右クリック → オプション）、設定で自動スナップショットをオフにしてください。オフの間はタイマーが存在しません。それでも拡張機能は、Chrome の起動時、インストールや更新の時、設定を変更した時に短時間だけ動作し、保存済みのデータを整理します。そのいずれもネットワークは使いません。

### YouTube 動画の一時停止

アイコンの右クリックメニューとショートカットキーにある「YouTube の動画をすべて一時停止」は、すべてのウィンドウで開いている YouTube タブの、再生中の動画と音声をすべて一時停止します。再生位置はそのままで、ミュート、タブを閉じる、再読み込みは一切行いません。

そのために、拡張機能には youtube.com へのアクセス（`https://*.youtube.com/*`、www、m、music を含む）が必要です。インストール時には要求しません。設定で「アクセスを許可」をクリックしたときに Chrome が確認し（その前にメニュー項目を選ぶと設定が開きます）、設定または chrome://extensions でいつでもアクセスを解除できます。アクセスが許可されると、求められるたびに、拡張機能に含まれている小さな関数を 1 つ、各 YouTube タブで実行します。この関数は一時停止を押し、いくつ停止したかを数えるだけです。ページの内容や視聴履歴など YouTube のものは何も読み取らず、YouTube に関する情報を保存したり送信したりすることもありません。アクセスがなければ、どのウェブページでも何も実行しません。

## データの保持

- 保存したセッションは、Tabinet のページで削除するまで保持されます。
- 自動スナップショットは入れ替え方式で保持されます。保護されていないスナップショットのうち最新のものだけを残し（既定は20件。件数は Tabinet の設定で選べます）、古いものは自動的に削除します。保護したスナップショットは、削除するまで残ります。ブラウザの再起動後に作られる「前回のセッション（復旧）」のスナップショットは自動的に保護され、その1つ前のものも同様です。それより古い復旧スナップショットは入れ替えの対象に戻り、ほかと同じように順に削除されます。自分で保護したものは、そのまま手元に残ります。スナップショットは1件ずつでも、まとめてでも削除できます。
- Tabinet のページの「セッションデータをすべて削除」は、保存したセッションとスナップショットをすべて直ちに削除します。設定は残ります。
- 拡張機能をアンインストールすると、Chrome が保存データをすべて削除します。

## 権限

この拡張機能には次の権限が必要です。

- **tabs**: 並べ替え、セッションの保存、Tabinet のページの開いているウィンドウ一覧のためにタブの URL とタイトルを読み取り、セッションの復元時にタブを作成します。
- **tabGroups**: 現在のウィンドウのタブグループを並べ替えて整理し、セッションの復元時にタブグループを作り直します。
- **storage**: 並べ替えの設定と言語の選択を Chrome の同期ストレージに保存し、保存したセッション、スナップショット、セッションの設定をこの端末のローカル ストレージにのみ保存します。
- **contextMenus**: 拡張機能アイコンの右クリックメニューに「集合！」、「すべてのウィンドウをセッションとして保存」、「YouTube の動画をすべて一時停止」を追加します。ウェブページにメニュー項目は追加しません。
- **unlimitedStorage**: 大きなセッションが Chrome のローカル ストレージの既定の上限を超えられるようにします。データの保存場所は変わらず、すべて端末の中に残ります。
- **favicon**: Tabinet のページのタブの横に、Chrome のローカルのファビコン キャッシュからサイトのアイコンを表示します。ネットワークからアイコンを取得することはなく、拡張機能がアイコンのデータを保存することもありません。
- **alarms**: 選んだ間隔で自動スナップショットを取るためのタイマーとして使います。自動スナップショットをオフにすると、タイマーは存在しません。
- **scripting**: 「YouTube 動画の一時停止」で説明したとおり、求められたときに YouTube の動画を一時停止するためだけに使います。下で許可したサイトでのみ動作します。
- **youtube.com へのアクセス**（任意、`https://*.youtube.com/*`）: 設定で「アクセスを許可」をクリックしたときにのみ要求し、設定から解除できます。動画の一時停止にのみ使い、YouTube のページからは何も読み取りません。

この拡張機能はインストール時にホスト権限を要求せず、コンテンツ スクリプトも宣言しません。youtube.com へのアクセスは任意で、許可するかどうかはあなたが決めます。Chrome 123 以降が必要です。

## データの利用

- タブの URL とタイトルは並べ替えの際に読み取られますが、並べ替えのために保存されることは**ありません**。
- セッションを保存したとき、または自動スナップショットが有効な間、上記のデータは端末のローカル拡張機能ストレージに**のみ**保存され、外部のサーバーに送信されることは**ありません**。
- 並べ替えの設定は Chrome に組み込まれたストレージ API で保存され、第三者や外部のサーバーと共有されることはありません。
- タブの並べ替え、求められたときの YouTube 動画の一時停止、セッションの保存、復元、検索、インポート、エクスポート以外の目的で、データが販売、共有、利用されることは一切ありません。

## 第三者のサービス

Tabinet は、第三者のアクセス解析、トラッキング、データ収集サービスを**使用しません**。
