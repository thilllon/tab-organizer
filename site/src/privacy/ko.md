# 개인정보처리방침 - Tab Organizer

최종 수정일: 2026년 10월 25일

## 개요

Tab Organizer는 브라우저 탭을 정렬하고 정리하며, 여러 창과 탭을 세션으로 저장, 복원, 검색, 가져오기, 내보내기할 수 있게 해 주는 Chrome 확장 프로그램입니다. 요청하면 YouTube 탭의 동영상을 일시중지하기도 합니다. 저희는 개인정보를 중요하게 생각합니다. 이 확장 프로그램이 하는 모든 일은 브라우저 안, 사용자의 기기에서 이루어집니다.

## 데이터 수집

Tab Organizer는 어떤 개인 데이터도 **수집하거나 전송하지 않습니다**. 네트워크 요청을 하지 않고, 방문한 페이지의 내용을 읽지 않으며, 분석, 추적, 원격 측정 도구를 쓰지 않습니다. 모든 작업은 브라우저 안에서 로컬로 처리됩니다. 웹페이지 안에서 실행하는 것은 YouTube 동영상 일시중지뿐이며, 그것도 사용자가 허용한 뒤에만 실행합니다(아래 "YouTube 동영상 일시중지" 참고).

### 무엇을, 어디에 저장하나요

세션을 저장할 때, 그리고 자동 스냅샷이 켜져 있는 동안(아래 참고), 확장 프로그램은 열린 창에 관한 다음 정보를 이 기기의 Chrome 로컬 확장 프로그램 저장소(`chrome.storage.local`)에만 저장합니다.

- 각 탭: URL, 페이지 제목, 고정된 탭인지 여부, 활성 탭이었는지 여부
- 각 탭 그룹: 이름, 색상, 접혀 있었는지 여부
- 각 창: 상태(일반, 최소화, 최대화, 전체 화면), 크기와 위치, 포커스된 창이었는지 여부
- 각 세션: 사용자가 붙인 이름(또는 자동으로 만든 기본 이름), 저장한 시각과 마지막으로 바뀐 시각, 똑같은 스냅샷을 두 번 저장하지 않도록 쓰는 탭 배치의 짧은 지문
- 세션 설정: 자동 스냅샷 사용 여부, 간격, 보관 개수, 큰 세션을 복원하는 방식

시크릿 창, 빈 창, 확장 프로그램 자체의 페이지는 저장하지 않습니다. Tab Organizer 화면에 보이는 사이트 아이콘은 Chrome 자체의 파비콘 캐시에서 가져오며, 확장 프로그램이 저장하지 않습니다.

이 데이터는 기기를 떠나지 않습니다. Google 계정으로 동기화되지 않고, 어떤 서버에도 업로드되지 않으며, 웹페이지에서 접근할 수 없습니다. 세션 데이터가 확장 프로그램 밖으로 나가는 유일한 경우는 사용자가 직접 내보내기를 선택할 때입니다. 내보내기는 사용자가 명시적으로 실행했을 때에만 파일을 만들거나 클립보드에 텍스트를 복사합니다.

정렬 환경설정(그룹 방식, 중복 탭 처리 방식)과 설정에서 고른 확장 프로그램 언어(고른 경우)는 확장 프로그램을 설치하거나 업데이트할 때 기록한 버전 번호와 함께 Chrome 동기화 저장소에 저장됩니다. Chrome 동기화를 켜 두었다면 이 환경설정, 그리고 그것만이 같은 Chrome 계정에 로그인한 기기 사이에서 동기화될 수 있습니다. 세션 데이터와 세션 설정은 동기화 저장소에 절대 저장되지 않습니다.

### 자동 스냅샷

자동 스냅샷은 **기본으로 켜져 있습니다**. 5분마다(또는 1분에서 24시간 사이에서 사용자가 고른 간격마다), 그리고 아이콘을 클릭해 정렬할 때마다, 확장 프로그램은 위에서 설명한 대로 열린 창의 배치를 기록합니다. 단, 마지막 스냅샷 이후 무언가 바뀌었을 때만 기록합니다. 스냅샷은 저장된 세션과 같은 로컬 저장소에 보관되며 같은 규칙을 따릅니다.

스냅샷을 끄려면 Tab Organizer를 열고(아이콘을 마우스 오른쪽 버튼으로 클릭 → 옵션) 설정에서 자동 스냅샷을 끄세요. 스냅샷을 끄면 타이머가 존재하지 않습니다. 그래도 확장 프로그램은 Chrome이 시작될 때, 설치되거나 업데이트될 때, 설정을 바꿀 때 잠깐 깨어나 저장된 데이터를 정돈합니다. 이 중 어느 것도 네트워크를 쓰지 않습니다.

### YouTube 동영상 일시중지

아이콘의 마우스 오른쪽 버튼 메뉴와 단축키에 있는 "모든 YouTube 동영상 일시중지"는 모든 창에서 열려 있는 YouTube 탭의 재생 중인 동영상과 오디오를 모두 일시중지합니다. 재생 위치는 그대로이며, 음소거하거나 탭을 닫거나 새로고침하지 않습니다.

이를 위해 확장 프로그램에는 youtube.com 접근 권한(`https://*.youtube.com/*`, www, m, music 포함)이 필요합니다. 설치할 때는 요청하지 않습니다. 설정에서 "접근 허용"을 누르면 Chrome이 묻고(그 전에 메뉴 항목을 고르면 설정이 열립니다), 설정이나 chrome://extensions에서 언제든 접근을 해제할 수 있습니다. 접근이 허용되면 사용자가 요청할 때마다 확장 프로그램에 들어 있는 작은 함수 하나를 각 YouTube 탭에서 실행합니다. 이 함수는 일시중지를 누르고 몇 개를 멈췄는지만 셉니다. 페이지 내용, 시청 기록 등 YouTube의 어떤 것도 읽지 않으며, YouTube에 관한 어떤 정보도 저장하거나 전송하지 않습니다. 접근 권한이 없으면 어떤 웹페이지에서도 아무것도 실행하지 않습니다.

## 데이터 보관

- 저장된 세션은 Tab Organizer 화면에서 사용자가 지울 때까지 보관됩니다.
- 자동 스냅샷은 순환 방식으로 보관됩니다. 보호되지 않은 스냅샷 중 가장 최근 것만 남기고(기본 20개, 개수는 Tab Organizer 설정에서 정할 수 있음) 오래된 것은 자동으로 지웁니다. 보호로 표시한 스냅샷은 사용자가 지울 때까지 남습니다. 브라우저를 다시 시작한 뒤 만들어지는 "이전 세션(복구됨)" 스냅샷은 자동으로 보호되며, 그 직전 것도 마찬가지입니다. 그보다 오래된 복구 스냅샷은 다시 순환 목록으로 돌아가 다른 스냅샷처럼 차례로 지워집니다. 사용자가 직접 보호로 표시한 스냅샷은 계속 보관됩니다. 스냅샷은 하나씩 또는 한꺼번에 지울 수 있습니다.
- Tab Organizer 화면의 "모든 세션 데이터 삭제"는 저장된 세션과 스냅샷을 모두 즉시 지웁니다. 설정은 남습니다.
- 확장 프로그램을 삭제하면 Chrome이 저장된 데이터를 모두 지웁니다.

## 권한

이 확장 프로그램에는 다음 권한이 필요합니다.

- **tabs**: 정렬, 세션 저장, Tab Organizer 화면의 열린 창 목록을 위해 탭의 URL과 제목을 읽고, 세션을 복원할 때 탭을 만듭니다.
- **tabGroups**: 현재 창의 탭 그룹을 정렬하고 정리하며, 세션을 복원할 때 탭 그룹을 다시 만듭니다.
- **storage**: 정렬 환경설정과 언어 선택을 Chrome 동기화 저장소에 저장하고, 저장된 세션, 스냅샷, 세션 설정을 이 기기의 로컬 저장소에만 저장합니다.
- **contextMenus**: 확장 프로그램 아이콘의 마우스 오른쪽 버튼 메뉴에 "모두 모으기", "모든 창을 세션으로 저장", "모든 YouTube 동영상 일시중지"를 추가합니다. 웹페이지에는 메뉴 항목을 추가하지 않습니다.
- **unlimitedStorage**: 큰 세션이 Chrome의 기본 로컬 저장소 한도를 넘을 수 있게 합니다. 데이터가 저장되는 위치는 바뀌지 않으며, 모든 데이터는 기기에 남습니다.
- **favicon**: Tab Organizer 화면에서 탭 옆에 Chrome의 로컬 파비콘 캐시에 있는 사이트 아이콘을 보여 줍니다. 네트워크에서 아이콘을 가져오지 않고, 확장 프로그램이 아이콘 데이터를 저장하지도 않습니다.
- **alarms**: 사용자가 고른 간격으로 자동 스냅샷을 찍기 위한 타이머로 씁니다. 자동 스냅샷을 끄면 타이머가 존재하지 않습니다.
- **scripting**: "YouTube 동영상 일시중지"에 설명한 대로, 사용자가 요청할 때 YouTube 동영상을 일시중지하는 데에만 씁니다. 아래에서 허용한 사이트에서만 동작합니다.
- **youtube.com 접근 권한** (선택, `https://*.youtube.com/*`): 설정에서 "접근 허용"을 누를 때만 요청하며, 설정에서 해제할 수 있습니다. 동영상 일시중지에만 쓰고, YouTube 페이지에서 아무것도 읽지 않습니다.

이 확장 프로그램은 설치할 때 호스트 권한을 요청하지 않고 콘텐츠 스크립트를 선언하지 않습니다. youtube.com 접근 권한은 선택 사항이며, 허용 여부는 사용자가 정합니다. Chrome 123 이상이 필요합니다.

## 데이터 사용

- 탭의 URL과 제목은 정렬하는 동안 읽히며, 정렬 과정에서 저장되지 **않습니다**.
- 세션을 저장할 때나 자동 스냅샷이 켜져 있는 동안, 위에 나열한 데이터는 기기의 로컬 확장 프로그램 저장소에**만** 저장되며 외부 서버로 전송되지 **않습니다**.
- 정렬 환경설정은 Chrome의 기본 저장소 API로 저장되며, 제3자나 외부 서버와 공유되지 않습니다.
- 어떤 데이터도 판매, 공유되지 않으며, 탭 정렬, 요청한 YouTube 동영상 일시중지, 세션의 저장, 복원, 검색, 가져오기, 내보내기 외의 목적으로 쓰이지 않습니다.

## 제3자 서비스

Tab Organizer는 제3자 분석, 추적, 데이터 수집 서비스를 **쓰지 않습니다**.
